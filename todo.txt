- sim/core/

1. Deterministic behavior

4. Reproducibility

---

## REQUIRED CHANGES

### 1. Add Global Seed Control (IMPORTANT)

Ensure full reproducibility:

- Add a single seed entry point (config or run.py)
- All randomness must use this seed
- No uncontrolled random calls outside seeded RNG

---

### 2. Introduce Experiment Runner Layer

Create a new file:

sim/experiments/runner.py

It must support:

- run_experiment(config, seed)
- run_multiple_experiments(list_of_configs)
- collect_results()

Each experiment must return structured output only.

---

### 3. Standardize Metrics Output (VERY IMPORTANT)

All simulation runs MUST return this exact schema:

{
  "experiment_name": str,
  "seed": int,
  "total_supply": float,
  "platform_revenue": float,
  "burned": float,
  "avg_visit_load": float,
  "survival_rate": float,
  "winner_connectors": list,
  "top_nodes": list
}

No extra fields allowed in final output.

---

### 4. Freeze Engine Behavior

- Do NOT modify mechanics or personality logic
- Only ensure engine is deterministic and cleanly called
- Remove any hidden randomness not controlled by seed

---

### 5. Add Comparison Utility

Create:

sim/experiments/compare.py

It should:

- take two experiment results (A and B)
- print side-by-side differences:
  - inflation difference
  - survival difference
  - revenue difference
  - winner shifts

Output must be CLI text only.
