## Context
We are adding a CLI interactive mode to RingWars.

This must NOT affect the existing experiment system.

The interactive mode will allow a human to participate as either:
- Connector (C*)
- Node (N*)

Environment:
- Termux (Android)
- CLI only
- No UI libraries
- Keep it lightweight

---

## Task

Create a new module:

sim/interactive/
  - cli.py
  - player.py

---

## Requirements

### 1. Entry Flow

When running:

python sim/interactive/cli.py

Prompt:

1. "Do you want to participate? (y/n)"
   - if "n" → exit

2. "Choose role:"
   - 1 = Connector
   - 2 = Node

3. Show available IDs based on scenario:
   - Connectors: C0 ... Cn
   - Nodes: N0 ... Nn

4. User selects ID

---

### 2. Human Player Class

Create:

sim/interactive/player.py

Class:

HumanPlayer:
- role (connector/node)
- id

Method:

choose_action(state)

If Connector:
- show available nodes
- show estimated cost (if possible)
- input: node id or "skip"

If Node:
- show incoming connectors (if any)
- input:
    1 = encourage (reduce cost)
    2 = neutral
    3 = discourage (increase cost)

Return structured action:
{
  "type": "connect" or "skip" or "influence",
  "target": node_id (if applicable),
  "mode": optional (for node)
}

---

### 3. Engine Integration

Modify run loop ONLY for interactive mode:

Each day:

- show day number
- show user status:
  - if connector: balance, wins, connections
  - if node: earnings, visit load, current ring holder

- call:
  action = HumanPlayer.choose_action(state)

- pass action into engine BEFORE other agents act

- other agents act normally
