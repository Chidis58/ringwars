# RingWars Social Mechanics Laboratory Report

## 🧪 Laboratory Transition Summary
The project has been successfully pivoted into a research-driven social mechanics laboratory. All UI/CLI development has been frozen to prioritize the observation of emergent social behaviors and economic stability.

### 🔬 Core Research Capabilities
1.  **Experiment Flag System**: Togglable mechanics in `sim/config.py` (e.g., `revenge_bidding`, `emotional_escalation`).
2.  **Observability Layer**: Raw event logging of `RING_TRANSFER`, `BANKRUPTCY_PREVENTED`, and `SATURATION_LOCK`.
3.  **Strategy Diversification**: Agents now utilize distinct behavioral profiles: **AGGRESSIVE**, **EXPLORER**, **DEFENSIVE**, and **WHALE**.
4.  **Automated Data Export**: Every run generates:
    *   `metrics.json`: Final state metrics.
    *   `history.json`: Tick-level state snapshots.
    *   `events.log`: Raw machine-readable event stream.
    *   `experiment_report.md`: Structured analysis summary.
