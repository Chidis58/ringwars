## Changes Made
1. **Global Seed Control**: All randomness is now managed via `random.Random(seed)` instances.
2. **Determinism**: 
   - Injected RNG into all agents and the simulation engine.
   - Replaced non-deterministic dictionary iteration with sorted keys in the engine.
   - Added tie-breaking logic in `connector.py` (sorting by ID when metrics are equal).
3. **Experiment Runner**: Created a layer to run, collect, and save experiment results as JSON.
4. **Comparison Tool**: Built a CLI utility to compare two JSON results side-by-side.
5. **Standardized Metrics**: All runs now output a strict schema including supply, revenue, burn, and survival rates.
