## Changes Made
1. **New Branch**: Created `feature/interactive-mode` to isolate interactive features from the main stable branch.
2. **Interactive Entry Flow**: Users can now run `python3 sim/interactive/cli.py` to start a session.
3. **Human Player Logic**: Implemented `HumanPlayer` class for manual decision-making.
4. **Engine Integration**: 
    - Added a hook in the engine to process human actions before AI agents.
    - Implemented "Node Influence" mechanics, allowing nodes to encourage or discourage connections.
5. **Daily Reporting**: Specific CLI status reports for human players each day.
